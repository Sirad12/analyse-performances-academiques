# 📊 Analyse des performances académiques d'étudiants

## 📌 Description
Analyse statistique des performances académiques d'étudiants 
par régression linéaire simple et multiple sous R.

## 🛠️ Technologies utilisées
- **R** — Langage principal
- **RStudio** — Environnement de développement
- **Régression linéaire** — Simple et multiple
- **Visualisation** — Graphiques et interprétation

## ✨ Fonctionnalités
- Régressions linéaires simples et multiples
- Analyse statistique des variables
- Visualisations et interprétation des résultats
